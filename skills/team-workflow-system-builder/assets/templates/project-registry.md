## Maintenance Rules

- Register a project only after successful workspace initialization.
- Update the row when stage, active version, location, artifact state, approval requirement/result, or template version changes.
- Prefer portable relative references when projects share a parent workspace.
- Do not copy project facts, client content, or detailed evidence into this registry.
