# Source Register

## Source Rules

- New sources enter this register before becoming formal facts.
- Unverified sources can support context, not confirmed conclusions.
- Conflicting sources stay `conflict-pending` until a decision is recorded.

## Register

| Source ID | Title | Type | Provider | Date / Period | Storage Path | Status | Applies To | Conflicts | Can Use |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| SRC-YYYYMMDD-01 |  | file / note / export / webpage / screenshot / email |  |  |  | pending / needs-original / needs-date / conflict-pending / verified / context-only / rejected |  |  | yes / no / limited |

## Status Definitions

| Status | Meaning |
| --- | --- |
| pending | Received but not checked |
| needs-original | Lacks original file, link, screenshot, or traceable source |
| needs-date | Date or effective period is unclear |
| conflict-pending | Conflicts with another source and needs a decision |
| verified | Can be used as formal evidence |
| context-only | Useful for background but not formal evidence |
| rejected | Not used |
