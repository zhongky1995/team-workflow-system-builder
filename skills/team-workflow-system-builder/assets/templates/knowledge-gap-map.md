# Professional Knowledge Gap Map

## 1. Purpose

Use this map to separate process problems from professional knowledge gaps.

Process gaps are solved by workflow, ownership, gates, templates, and governance.

Knowledge gaps are solved by methods, standards, examples, terminology, domain rules, and checklists.
